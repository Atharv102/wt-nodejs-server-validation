    Node.js Server Architecture & Validation Rules

    1. Routing & Modules

    Organized with modular Express Router (routes/enrollmentRoutes.js) separating GET, POST, and DELETE methods cleanly from the application logic.

    2. Server Validation Middleware

    Enforces business rules on the backend (middleware/validator.js). Rejects invalid payloads with HTTP 400 Bad Request before database insertion.

    3. Input Sanitization (XSS Defense)

    Input sanitizer (middleware/sanitizer.js) strips all HTML/script tags from incoming payloads, normalizes spaces, and lowercases emails.
